One case reference format

Write case numbers the same way everywhere, and find them however they're typed.

Proposed

Try "auth 2949", "0874/02/26" or "688".

    Case references before October 2024 start AUTH/. From the 2024 Code they start CASE/. Both are searchable.

    What we saw

    References changed from AUTH/2949/3/17 to CASE/0685/08/25. The press release writes "Case/0685/08/25", and an advertised sanction is titled "Advert - Sanofi - SANOFI – CASE/0688/08/25".

    What changes

    One format everywhere (CASE/0685/08/25), a short note explaining older AUTH/ references, and search that finds a case whether someone types "case 685", "0685/08/25" or the full reference.

Take "Comes into operation" out of the Code's title

Describe the Code as it is today, in search results and browser tabs.

Proposed

www.pmcpa.org.uk › the-codeThe ABPI Code of Practice 2024 | PMCPAThe ABPI Code of Practice for the Pharmaceutical Industry, in effect since 1 October 2024. Search the Code clause by clause, with Q&As, guidance and cases.
The ABPI Code of Practice 2024 | PMCPA

What we saw

The interactive Code page title is "2024 Interactive ABPI Code of Practice - Comes into operation 1 October 2024", two years after it did. That's what search engines and browser tabs show.

What changes

Title the page "The ABPI Code of Practice 2024 | PMCPA" and state once, on the page, that it has been in effect since 1 October 2024.

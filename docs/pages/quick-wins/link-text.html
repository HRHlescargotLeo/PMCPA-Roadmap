Link text that says where it goes

Replace "click here" with links that make sense on their own, and label downloads.

Medium impactSmall change

Today on pmcpa.org.uk

Please use our tool (click here) to make sure you have come the right place for your complaint.

An interactive e-learning module targeted at individuals requiring an overview of the ABPI Code. Click here for further details

2024 ABPI Code of Practice (PDF, [size])

What we saw

"Click here" and "tool (click here)" appear on the homepage, the Media page and Make a complaint. Download links such as "2024 ABPI Code of Practice" don't say they open a PDF.

What changes

Descriptive link text throughout, and the file type and size on every download.

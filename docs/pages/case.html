Prototype 2 of 5 · Case report

What we're proposing

A case report you can read on screen. The outcome, key dates and sanctions are at the top; a table shows the ruling on each clause, linked to that clause in the Code; a timeline shows how the case moved. The full report is in sections with a contents list, and the PDF is still there to download. Underneath, other cases on the same clause and about the same company, plus copy link, a suggested citation and print.

Why

Case pages already hold the facts as fields, but the full report is a PDF and clause numbers are plain text, so moving from a ruling to the clause it applies to, or to similar cases, means starting again from search. We also saw a 2017 case showing "November 2007 Review", which a structured template would catch.

Try another case from the finder; this page opens any case with ?case=. The report text is placeholder: real reports would fill these sections.
